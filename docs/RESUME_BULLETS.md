# 简历项目描述

**中小企业融资担保尽调 Agent｜独立产品设计与全栈开发**

- 面向融资担保项目经理设计尽调协作工作台，打通文本型 PDF/Word/Excel 解析、标准事实抽取、跨材料核验、人工复核与报告导出，并以页码、段落和单元格实现证据追溯。
- 将收入/纳税/流水、应收增速、现金流、杠杆、客户集中度、关联方、融资用途、抵押物和债务到期沉淀为 10 项确定性规则；缺字段返回“材料不足”，避免模型补全或零值误判。
- 构建制造、贸易、服务三套虚构评测案例；确定性回归中风险召回率和引用精确率均为 100%、章节引用覆盖率 96.67%，后端 13 项及桌面/移动端 4 项自动化测试通过。

面试时必须补充：上述指标来自虚构标准案例，不代表真实业务效果。真实模型三次评测完成后，再增加模型成本、稳定性和 Agent 相对一次性 Prompt 的提升数据。
