# 两分钟演示视频脚本

自动化无旁白底稿：[due-diligence-demo.webm](assets/due-diligence-demo.webm)。投递前建议按下列脚本重新录制本人旁白。

1. `0:00–0:15`：打开华辰债券项目驾驶舱，展示 2 亿元、3 年期、AA-/AA+ 和虚构保证人，说明系统只辅助发行担保尽调，不自动审批。
2. `0:15–0:35`：进入材料页的冻结主体资料，展示公司身份、三个完整年度三张报表、八项确定性指标和证据页码，再展示募集说明书与评级报告已就绪。
3. `0:35–0:55`：明确当前为统一“完整尽调”，并在财务与偿债核验页展示 DSCR、本金集中到期压力、评级与主体档案口径勾稽、政策版本、阈值和 `insufficient` 状态。
4. `0:55–1:22`：切换融益冲突案例，在复核中心并列查看募集说明书和评级报告的金额断言；切换景和案例确认治理候选风险并关闭尽调任务。
5. `1:22–1:43`：进入担保及反担保页，展示 3×3 风险矩阵、保证责任范围、抵押顺位和可执行性建议，打开证据抽屉。
6. `1:43–2:00`：打开 17 章专业报告，说明其中六章使用受控 LLM 润色，其余为确定性模板；展示统一“完整尽调”和补充核验材料警示，最后强调 Agent 不输出承保、额度、费率或审批决定。

重新生成底稿：启动本地服务后在 `frontend` 运行 `npm.cmd run record:demo`。
