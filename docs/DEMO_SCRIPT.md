# 两分钟演示视频脚本

自动化无旁白底稿：[due-diligence-demo.webm](assets/due-diligence-demo.webm)。投递前建议按下列脚本重新录制本人旁白。

1. `0:00–0:15`：切换制造、贸易、服务三个虚构案例，说明项目面向担保项目经理，不自动审批。
2. `0:15–0:35`：进入材料与事实，展示不同文件类型、材料缺口、置信度和人工修正。
3. `0:35–1:00`：展示核验的 `passed / warning / insufficient`，强调缺字段不会按零计算。
4. `1:00–1:20`：打开一项风险和证据抽屉，定位 Excel 区域或 Word 段落。
5. `1:20–1:45`：进入报告，编辑章节、标记复核并导出 Word。
6. `1:45–2:00`：展示三案例评测、测试结果和边界，明确所有案例均为虚构数据。

重新生成底稿：启动本地服务后在 `frontend` 运行 `npm.cmd run record:demo`。
