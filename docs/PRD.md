# PRD：研担融资担保尽调 Agent

## 用户与问题

核心用户是融资担保项目经理和风险审查人员。尽调需要在财务、税务、流水、合同、债务和抵押材料间反复核对，数字口径冲突难追溯，报告初稿耗时且容易缺失证据。

## 产品目标

- 完成“创建项目 → 上传 → 事实复核 → 交叉核验 → 风险 → 报告 → 导出”闭环。
- 所有材料事实、核验和风险均可回到 PDF 页码、Word 段落或 Excel 单元格。
- Agent 只提供风险和核验动作，不给出通过/拒绝结论。

## 用户流程

1. 用户确认只上传公开或虚构材料，录入融资主体、金额、期限和用途。
2. 系统解析并分类文本型 PDF、DOCX、XLSX，展示质量和材料缺口。
3. 确定性标签抽取与模型结构化抽取形成标准事实；用户可修正并标记人工确认。
4. 10 项规则输出通过、预警或材料不足；只有预警可以产生风险。
5. 系统用事实与风险模板生成报告，模型只能在允许证据内润色。
6. 用户查看证据、编辑章节、标记复核并导出报告。

## 核心验收

- 缺字段不能作为 0 计算，冲突来源不能由 Agent 擅自选择。
- 模型只能返回注册字段和输入中存在的 `source_id`。
- 新增数字或非法引用导致章节回退到确定性模板。
- 自定义项目未配置模型时停在 `model_required`，不生成推测性风险。
- 非演示项目所有读取、修改、引用和导出均验证项目令牌。

## 非目标

不处理扫描件 OCR，不连接真实工商或征信系统，不替代审批人员，不使用实习单位客户数据、内部知识库、模板或 Prompt。
